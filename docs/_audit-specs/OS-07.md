# OS-07 — BGSM/BGEM material writer + offline NIF/collision validators as MCP tools

**verdict:** confirmed-open | **effort:** L | **risk:** med | **recommend_now:** True

**area:** art pipeline (NIF/material/collision)

## What's missing
BGSM/BGEM binary authoring lives only as throwaway staging scripts (make_bgsm.py docstring path is deleted/throws; deployed BGSMs actually came from Note.BGSM). nif_tri_decode.py is known-buggy (garbage on the vanilla donor, so every 'invisible mesh' verdict is untrustworthy). No fo4_validate_nif offline gate (the exact layer that catches silent no-shows), no fo4_create_bgsm, no fo4_splice_collision.

## Evidence (code-grounded)
All four sub-claims verified against on-disk code, not docs.

1) nif_tri_decode.py is buggy — EMPIRICALLY CONFIRMED. Ran `tools/blender/scripts/nif_tri_decode.py` on the golden vanilla donor `staging/coupon-mod/_vanilla_nif/Meshes/Props/Money_Prewar.nif`: it decodes numTriangles=65535, numVertices=65535, dataSize=5, vertexSize=4294967295 (0xFFFFFFFF underflow) yet prints "VERDICT: geometry renderable". The offset walk in `decode_tri` (nif_tri_decode.py:37-56) is wrong — the radius read lands on 8.63 by luck but the tri/vert/size quad is garbage, so the invis heuristic at lines 67-71 is meaningless. Every "INVISIBLE-RISK" verdict from it is untrustworthy.

2) make_bgsm.py throws — CONFIRMED. Template `_mat_probe/Materials/Interface/Newspaper/DN101Note.BGSM` (make_bgsm.py:27) does NOT exist on disk; `TEMPLATE.read_bytes()` at line 73 raises FileNotFoundError. Docstring claims DN101Note provenance.

3) Deployed BGSMs came from Note.BGSM — CONFIRMED byte-exact. `staging/coupon-mod/materials/PrewarCoupons/coupon_cram.bgsm` differs from `_template/Note.BGSM` in EXACTLY one header byte (offset 42 / 0x2a, AlphaTest, flipped 1->0 by the P0 patch) and has a byte-identical 128-byte shader tail. It is NOT make_bgsm output, NOT DN101Note-derived. No reproducible authoring tool exists.

4) No MCP tool for any of the three — CONFIRMED. 35 @mcp.tool() in server.py (none NIF/BGSM/collision); manifest has no nif/bgsm/splice entry; grep of mcp-server/ for nif_tri_decode|splice_collision|make_bgsm = 0 hits (scripts unwired). MSWP path tools.py:1956-1978 only references .bgsm PATHS in plugin records, never authors binaries.

Preconditions for building exist: golden donor NIF on disk; 6616-file `staging/coupon-mod/_vanilla_bgsm/` library INCLUDING the exact prop template the doc wants to lock (`_vanilla_bgsm/Materials/Props/NoteLowPoly.BGSM`); BGEM samples present (e.g. _vanilla_bgsm/Materials/actors/Bloatfly/*.BGEM); BGSM shader flags (AlphaTest@42, IsDecal@47, TwoSided@48) live in the stable 63-byte header BEFORE the variable string table, so a writer can author+cross-check them deterministically. splice_collision.py (tools/blender/scripts/splice_collision.py:56-74) already works (block-layout assert + Block-Sizes patch) but is a CLI script, not gated/wrapped.

Caveat folded in: the OS proposed offsets in the diagnosis doc are correct as ABSOLUTE header offsets (42/47/48), not string-relative — verified.

## Concrete plan

1. P1-1 (golden-file decoder fix) FIRST: create new module mcp-server/fo4_mcp/nif_inspect.py. Port+fix nif_tri_decode logic. Add a fixture: copy `_vanilla_nif/Meshes/Props/Money_Prewar.nif` -> `fixtures/nif/Money_Prewar.nif` (this is the golden donor). Write test_nif_inspect.py asserting the decoder yields SANE values (radius~6-9, 0<numTri<60000, 0<numVert<60000, vertexSize in {plausible BSVertexDesc-derived sizes}, dataSize>0) on the golden file. Iterate the BSTriShape field walk until the golden assertions pass — the current decode_tri offset chain is wrong (the 65535/0xFFFFFFFF underflow shows the BoundingSphere/header boundary is misaligned for BSVersion 130). Cross-check geometry by validating numTri*3 index span and numVert*vertexSize fit inside dataSize.
2. P1-2 (fo4_validate_nif) on top of the fixed decoder: add `def fo4_validate_nif(cfg, nif_path, *, model_record=None) -> dict` to nif_inspect.py. READ-ONLY (no write, so no safety gate needed). Checks: (a) at least one BSTriShape with numVert>0 and numTri>0 (renderable geometry); (b) bound radius>0 AND non-degenerate center; (c) resolve BSShaderTextureSet / BSLightingShaderProperty material chain — each referenced .bgsm and its diffuse .dds must resolve under a provided textures/materials root (cfg or arg); (d) AlphaTest-vs-diffuse-alpha cross-check: open the resolved .bgsm header byte 42; if AlphaTest==1, flag a warning that the diffuse DDS must have meaningful alpha (the silent-no-show class). Return {ok, geometry:[...], material_chain:[...], warnings:[...], verdict}. OBND non-zero is a RECORD-level check — keep it where it already is (the CLI read-back emits objectBoundsZero per docs line 42), and have fo4_validate_nif accept an optional model_record dict to fold OBND into the verdict, rather than re-parsing the esp.
3. P1-7 (fo4_create_bgsm) — add mcp-server/fo4_mcp/bgsm.py. Lock the prop preset: copy `_vanilla_bgsm/Materials/Props/NoteLowPoly.BGSM` -> `fixtures/bgsm/NoteLowPoly.BGSM` as the canonical opaque-prop template (NOT Note.BGSM, NOT the deleted _mat_probe path). Implement: parse(buf) (63-byte fixed header + 9 length-prefixed strings + 128-byte tail, per make_bgsm.py:41-54 which round-trips), set_diffuse/normal/specular strings, optionally override the header shader flags (AlphaTest@42, IsDecal@47, TwoSided@48) with explicit defaults AlphaTest=0/IsDecal=0/TwoSided=0 for an opaque card, rebuild, and SELF-VERIFY round-trip (re-parse == intended). Signature: `def fo4_create_bgsm(cfg, out_path, *, diffuse, normal=None, specular=None, preset='note_prop', alpha_test=0, two_sided=0) -> dict`. Output MUST land under staging/ — call safety.check_write(out_path, repo_root); honor ALLOW (staging) vs ALLOW_DIFF_GATED. This REPLACES make_bgsm.py (which throws) and produces reproducible BGSMs instead of the Note.BGSM-hijack artifact.
4. P1-5 (fo4_splice_collision) — add mcp-server/fo4_mcp/collision_splice.py wrapping the proven splice_collision.py logic (block-layout assert + COLLISION_TYPES splice + Block-Sizes patch). Signature: `def fo4_splice_collision(cfg, donor_nif, target_nif, out_nif) -> dict`. Add: (a) structured block-type diff in the return (donor vs target type lists, which indices spliced, byte-size delta per block — surface the splice_collision.py:67 print as data); (b) post-splice byte-equality assertions of the spliced collision blocks vs donor blocks (prove the Havok blob is donor-identical); (c) safety.check_write(out_nif). READ donor/target freely. Reuse splice_collision.parse/splice rather than re-implementing.

Register the three tools in server.py as new @mcp.tool() wrappers (fo4_validate_nif, fo4_create_bgsm, fo4_splice_collision), each delegating through the existing _safe(lambda: ...) pattern (server.py:495). ## Test strategy
Mirror the existing mcp-server/tests pattern (test_tools_create_record.py / test_plugin_format.py): pure-Python tools, no live binary, so tests run unconditionally (no skip-if-unbuilt). (3) fo4_create_bgsm: round-trip the NoteLowPoly fixture byte-exact (parse->rebuild==original, like make_bgsm.py:77); diffuse-swap re-parses to the new path with tail/normal/spec intact; alpha_test=0 sets header byte 42==0; output OUTSIDE staging raises PathForbiddenError (assert via safety.check_write, like test_tools_create_record forbidden-output test). (4) fo4_splice_collision: splice donor into a copy with identical block layout -> spliced collision blocks byte-equal donor; mismatched-layout target -> AssertionError/Fo4McpError; out path outside staging -> PathForbiddenError. Use tmp_path repos + the _cfg() helper already in the test suite.
